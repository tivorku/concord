# MDN: Market Decentralized Network

P2P-протокол координации распределенных агентов. Предназначен для устранения коллизий и оптимизации транзакционных издержек в состязательных средах без центрального сервера.

## Сетевой стек
*   **Фундамент:** Go, `libp2p`.
*   **Транспорт:** QUIC (UDP) — основной, TCP — fallback.
*   **NAT Traversal:** Relay v2 + DCUtR (Hole Punching).
*   **Дискавери:** Гибридное. GossipSub (анонс < 1с) + Local DHT (поиск прокси < 20с).
*   **Изоляция:** Кастомный префикс протокола `/mdenet` + XOR-Pepper для всех Protocol ID.

## Консенсус и Очередь
*   **Синхронизация:** Часы Лампорта + Network Time Offset (калибровка по реле через HTTP).
*   **Алгоритм выбора лидера:** Детерминированный Tie-breaking (Priority -> JoinedAt -> PeerID).
*   **Формула приоритета:** $P = S^2 / W$
    *   `S` (Satiety): Налог на удержание ресурса + количество выполненных действий.
    *   `W` (WaitTime): Логическое время ожидания в тиках.
*   **Экономический цикл:** Слайдинг (деление S на 2) каждые 15 минут. Только для узлов с подтвержденным аптаймом.

## Безопасность и Стелс
*   **MDN Shield:** Пре-авторизация через HTTP Knock.
*   **Фильтрация:** ConnectionGater на уровне `accept()`. Отсекает 99% Mainnet-шума до Noise-хендшейка.
*   **Memory:** MemGuard (mlock). Защита ключей от дампов памяти и Swap.
*   **Анонимность:** Стелс-туннелирование прикладных запросов через Mesh-соседей.

## Производительность (1 vCPU / 4GB RAM)
*   **vCPU Load:** 5–8%.
*   **Network:** Корректная работа и подтверждение Public IP за провайдерским CGNAT.
*   **Capacity:** До 1024 одновременных резерваций на узел Relay.

## Roadmap
*   **v0.2:** Федерализация реле (User-run nodes).
*   **v0.3:** Multi-tenant Strategist (200+ аккаунтов на одну ноду).
