## Concord - децентрализованная сеть, координирующая действия продавцов Маркета Т2
### Зачем?
Цель сети в том, чтобы **повысить эффективность** каждой отдельной продажи на Маркете Т2 и **добиться снижения трат** на продажу лотов каждого участника сети.
### Каким образом она функционирует?
Сеть написана на языке **Go** с библиотекой **libp2p**. Связка этих инструментов позволяет достичь **высокой скорости обработки сообщений**, а также **высокой степени децентрализации**. Архитектура разделена на 2 составляющих:
* **Curcuit Relay** - это транспортный протокол, который позволяет двум узлам в P2P-сети обмениваться данными через **третий, промежуточный узел (реле)**, если они не могут установить прямое соединение друг с другом.
Используется как **необходимый** элемент для связности сети в условиях таких ограничений, как **CGNAT**.
* **Клиент** - участник сети, подключающийся к сети **через Реле** при отсутствии собственного постоянного IP или **напрямую через глобальный DHT**. На устройстве Клиента выполняется вся логика **обработки сообщений** от других участников сети и **принятия решений** в соответствии с поступающими данными.
### Ключевые нововведения и сетевые оптимизации

В рамках разработки архитектуры сети `Denet` был решен ряд фундаментальных проблем распределенных систем, сетевой безопасности и производительности в условиях ограниченных ресурсов мобильных устройств:

#### 1. Оптимизация времени вхождения в сеть (Low-latency Discovery)
* **Решение:** Вместо стандартного медленного поиска через глобальную таблицу Kademlia DHT (холодный старт до 120 секунд) внедрен двухуровневый алгоритм обнаружения на базе протокола GossipSub. 
* **Результат:** Использование выделенного глобального метатопика (`_global_discovery`) для мгновенного обмена пирами (Peer Exchange) сократило время инициализации сетевого окружения и подключения к целевому шарду **со 120 до 1 секунды**.

#### 2. Обход систем Deep Packet Inspection и маскировка трафика (uTLS Spoofing)
* **Решение:** Для интеграции с внешними API в условиях сетевых ограничений и блокировок реализована инкапсуляция прикладного трафика. 
* **Результат:** Сетевые запросы маскируются под легитимных клиентов с помощью динамической подмены TLS-отпечатков (**JA3 fingerprinting** через `uTLS`) непосредственно внутри P2P-стрима, что нейтрализует детекцию сигнатурными анализаторами DPI.

#### 3. Асимметричная P2P-архитектура и оптимизация ресурсов
* **Решение:** Для минимизации энергопотребления и сетевой нагрузки на мобильные устройства внедрена асимметричная схема ролей.
* **Результат:** Мобильные клиенты функционируют строго в режиме `dht.ModeClient`, делегируя тяжелую работу по маршрутизации и поддержанию связанности выделенному серверу-реле. Это исключает фоновые прерывания модема и сохраняет заряд батареи.

#### 4. Безопасность транспортного уровня и защита от спама (Dynamic Gating)
* **Решение:** Реализован двухуровневый фильтр входящих соединений (`ConnectionGater`) на уровне реле с интеграцией динамического белого списка.
* **Результат:** Метод `InterceptAccept` блокирует неавторизованные узлы на уровне IP-адресов **до прохождения ресурсоемкого криптографического хендшейка** (Noise/TLS), предотвращая DDoS-атаки на инфраструктуру реле. Авторизация происходит по гибридной схеме (через легковесный HTTP-сервер).

#### 5. Детерминированный распределенный Ledger
* **Решение:** Логика координации вынесена на уровень синхронного конечного автомата, где каждый узел независимо рассчитывает приоритеты на основе сетевого времени и наблюдаемых аномалий в поведении участников.
* **Результат:** Сеть устойчива к модификации исходного кода клиентами. Попытки искусственного завышения приоритета или отправки ложных репортов пессимизируются локальными Ledger-ами честных узлов на основе правил консенсуса, не требуя верификации через закрытые API.
## Запуск клиента
Требования:
* ОС: Windows 10+, Linux, Android
### Быстрая установка
```
curl -sSL https://raw.githubusercontent.com/tivorku/concord/main/install.sh | bash
```
### Termux
```
pkg update && pkg upgrade -y
pkg install git golang -y
git clone https://github.com/tivorku/concord.git
cd denet
go build -ldflags "-checklinkname=0" .
./concord
```
