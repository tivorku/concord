# MDN: Market Decentralized Network

Децентрализованная инфраструктура координации распределенных агентов. Архитектура разделена на два независимых компонента: **MDN Relay** и **MDN Client**.

---

## 🛰 MDN Relay
*Служебный узел инфраструктуры, обеспечивающий связность и безопасность сети.*

*   **Внеполосная авторизация (HTTP Knock):** Реализация эндпоинта для регистрации PeerID. Автоматическое внесение IP-адреса клиента в Whitelist.
*   **L4 Firewall (ConnectionGater):** Фильтрация входящих соединений на этапе `accept()`. Сброс пакетов от неавторизованных узлов Mainnet до выполнения Noise-хендшейка.
*   **Ресурсный менеджмент (rcmgr):** Жесткие лимиты на `Transient Scope` (24 одновременных хендшейка). Нагрузка на 1 vCPU снижена со 100% до **5–8%**.
*   **Сетевой Оракул:** 
    *   **IP-шлюз:** Работа в режиме `Global DHT ModeServer` для обеспечения кворума Identify/AutoNAT клиентам за CGNAT.
    *   **Time Oracle:** Трансляция эталонного серверного времени для синхронизации эпох.
*   **MDN Routing:** Ведение локальной таблицы маршрутизации (`/mdenet`) для изоляции сети.

---

## 💻 MDN Client
*Автономный агент, выполняющий прикладную логику и участвующий в консенсусе.*

*   **Гибридное обнаружение (Discovery):** 
    *   **GossipSub:** Мгновенный поиск соседей через мета-топики (< 1 сек).
    *   **Local DHT:** Поиск прямых адресов для проксирования через локальный префикс (< 10 сек).
*   **Синхронизация и Время:**
    *   **Network Time Offset:** Калибровка времени относительно реле при старте.
    *   **Часы Лампорта:** Упорядочивание событий в распределенном реестре.
*   **Алгоритм консенсуса:** 
    *   **Fair Queuing:** Формула приоритета $P = S^2 / W$.
    *   **Sliding Window:** Принудительная дефляция Satiety ($S$) каждые 15 минут.
    *   **Uptime Penalty:** Заморозка Satiety при уходе в оффлайн (пропуск слайдинга).
*   **Стелс-технологии:**
    *   **Peer-as-Proxy:** L4-туннелирование прикладных запросов через соседей по Mesh-сети.
    *   **Protocol Masking:** XOR-маскировка Protocol ID секретным ключом (Pepper).
    *   **Fingerprinting:** Использование `uTLS` для эмуляции TLS-отпечатков мобильных устройств.
*   **Безопасность:**
    *   **Memory Enclaves:** Защита ключей в памяти через `memguard` (mlock/mprotect).
    *   **State Reconciliation:** Автоматическое восстановление локального состояния при получении `SYNC_CORRECTION` от сети.
